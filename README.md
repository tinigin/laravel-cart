# Octane Cart

Пакет корзины товаров для Laravel Octane с драйверами `database` и `session`.

- Идентификатор корзины хранится в защищённом (зашифрованном) cookie.
- Срок жизни корзины автоматически продлевается при каждом обращении.
- Просроченные корзины можно удалять командой `cart:clean`.

## Установка

```bash
composer require tinigin/laravel-cart
